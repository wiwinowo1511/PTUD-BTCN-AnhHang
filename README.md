# Bài tập cá nhân Buổi 2 – Phát triển ứng dụng TMĐT

## 1. Giới thiệu
Bài tập tiếp tục phát triển website trang chi tiết sản phẩm Hasaki từ Buổi 1, tập trung thực hành HTML5 và CSS3.

## 2. Website tham khảo và khu vực cải tiến
- Website tham khảo: [Hasaki.vn](https://hasaki.vn/)
- Khu vực cải tiến: Trang chi tiết sản phẩm, tập trung vào cụm nút mua hàng và bố cục hiển thị thông tin sản phẩm.
- Xem website: [GitHub Pages](https://wiwinowo1511.github.io/PTUD-BTCN-Buoi1-AnhHang/)

## 3. Kỹ thuật HTML5/CSS3 đã thực hành
- Sử dụng các thẻ HTML5 để tổ chức nội dung trang.
- Áp dụng CSS selector để định dạng các thành phần.
- Sử dụng Box Model để điều chỉnh kích thước, khoảng cách và đường viền.
- Dùng **Flexbox** hoặc **CSS Grid** để bố trí giao diện.

## 4. Hướng dẫn chạy website
Mở file `index.html` bằng trình duyệt web.

## 5. Những thay đổi đã thực hiện
